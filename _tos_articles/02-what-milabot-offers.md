## 2. What MilaBot offers

The current feature set includes the following. `/help` and the command options available in Discord explain how to use the installed version.

| Area | Features |
| --- | --- |
| Social moments and entertainment | Hugs, headpats, pokes, kisses through "/yuri", licks, spanks, optional return actions, summons, fortune cookies, "/8ball", "/gaycounter", "/sheep", Truth or Dare, coin flips, and dice rolls. |
| Games | Blackmila, Sloths, 4 In A Row, AuctionWar, ExpansionWar, Knucklebones, Knucklebones Expanded, Battlesheep, and Flockade, with the supported player and computer-opponent options. |
| Economy and collections | Daily and weekly rewards, balances, currency and Expansion Orb leaderboards, the Milacoin shop, baking, Patisserie collections, Vitrine candy and plate loadouts, ShowOff battles, customer requests, and bakery upgrades. |
| Virtual wagers | "/gamble_coinflip", "/gamble_slots", and "/gamble_blackmila", using the Bot’s virtual currency. |
| Images and messages | Avatar and banner retrieval, avatar frames and wanted posters, emoji enlargement, emoji or sticker copying through supported media options, and message quotes with theme controls. |
| Server tools | Bans, kicks, timeouts and timeout removal, role assignment, role-button panels and their editing or retrieval, role information, server statistics, and ticket threads. |
| Utilities | LGBTQIA+ dictionary lookups, measurement conversions, text encoding and decoding, help, and latency checks. |

Availability differs between versions. Keyword reactions operate only in a gateway version with the required message access, not in the current Worker version. Features may change, be restricted, or be retired as the Bot develops. A command or asset left in the source repository is not a promise that it is available in the hosted Bot.
