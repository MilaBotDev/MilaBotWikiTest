## 5. Server administration and tickets

Server administrators are responsible for choosing appropriate permissions, role hierarchy, channel access, and who may use moderation tools. Review the target, reason, duration, and role before requesting an action. A permitted command can change a member’s access or remove them from a server.

Role buttons can grant or remove the configured roles. Administrators must check the permissions attached to those roles and the audience that can use each panel. Automated checks reduce mistakes but do not replace server oversight.

Tickets create Discord threads with access determined by Discord permissions. Server staff with appropriate access may read them. Locking or archiving a ticket does not delete it or promise confidentiality from staff. MilaBot’s ticket feature is not an emergency or confidential reporting service.

Server moderation decisions belong to the server’s staff. Raise an appeal with them; contact us when the concern is a Bot malfunction or misuse of the service.
