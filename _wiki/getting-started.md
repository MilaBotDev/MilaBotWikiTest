## Find a command

In a Discord conversation where MilaBot is available, type `/` and choose a MilaBot command. Discord shows required inputs and available choices. **/help** opens the bot’s own help browser; the [command directory]({{ '/wiki/commands/' | relative_url }}) lists the public commands in this wiki.

Some tools work on an existing message. Open its context menu and select **Apps** to find **Uwuify**, **Clone Emoji**, and **Clone Sticker**.

## Start your Patisserie

1. Run **/bake** to receive your first treat. Baking has a three-hour cooldown.
2. Open **/patisserie** to view your collection and reward bonuses.
3. Claim **/daily** and **/weekly** to build a Milacoin balance.
4. Open **/customer** and select a treat matching the daily visitor’s clue. You have one attempt a day.
5. Equip a discovered treat in **/vitrine**, then run **/showoff** to earn XP and coins.
6. Buy plates in **/shop** and earn Expansion Orbs from customers to upgrade your bakery.

The [Patisserie guide]({{ '/wiki/patisserie/' | relative_url }}) explains how these systems connect.

## Play a game

Try **/4inarow** or **/knucklebones** without an opponent to play MilaBot. Supply an opponent to play another user. The [games guide]({{ '/wiki/games/' | relative_url }}) covers the larger board games and their rules.

## Set up a server

Moderators can use role buttons, tickets, giveaways, and moderation commands. Start with [server tools]({{ '/wiki/server-tools/' | relative_url }}); these features need appropriate server permissions.

## If a command is unavailable

Check that you selected MilaBot’s command, that it is available in the current conversation, and that your role can use it. Server-only commands cannot run in direct messages. An active cooldown or a missing item is explained in the bot’s response.

For help, visit the [MilaBot support server](https://discord.gg/Gff3rasUn3). Use **/privacyanddata** for the bot’s private data controls.
