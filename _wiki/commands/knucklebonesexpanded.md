## How to use

Type **/knucklebonesexpanded** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>opponent</code></td><td>User</td><td>No</td><td>Choose a user to play against (Leave empty to play against MilaBot).</td></tr>
<tr data-wiki-entry><td><code>board</code></td><td>Text</td><td>No</td><td>Choose the board size.<br>Choices: 3x3 (<code>3</code>), 4x4 (<code>4</code>)</td></tr>
<tr data-wiki-entry><td><code>items</code></td><td>Yes / no</td><td>No</td><td>Enable items which players can get.</td></tr></tbody></table>
