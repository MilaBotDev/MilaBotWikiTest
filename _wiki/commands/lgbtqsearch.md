## How to use

Type **/lgbtqsearch** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>term</code></td><td>Text</td><td>Yes</td><td>What you want to search for (e.g. bi, hrt).</td></tr>
<tr data-wiki-entry><td><code>discreet</code></td><td>Yes / no</td><td>No</td><td>Only show the response to you.</td></tr></tbody></table>
