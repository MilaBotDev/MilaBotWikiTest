## How to use

Type **/leaderboard** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>scope</code></td><td>Text</td><td>No</td><td>Choose worldwide/serverwide leaderboard.<br>Choices: Worldwide (<code>worldwide</code>), This Server (<code>server</code>)</td></tr>
<tr data-wiki-entry><td><code>category</code></td><td>Text</td><td>No</td><td>Choose what the leaderboard shows.<br>Choices: Currency (<code>currency</code>), Expansion Orbs (<code>orbs</code>)</td></tr></tbody></table>
