## How to use

Type **/rolebuttonsfetch** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

This command is for servers.

Default member permissions: **Administrator**. Server command settings can further restrict availability.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>message_id</code></td><td>Text</td><td>Yes</td><td>The ID of the RoleButtons message to fetch.</td></tr>
<tr data-wiki-entry><td><code>channel</code></td><td>Channel</td><td>No</td><td>The channel containing the message. Defaults to this channel.</td></tr>
<tr data-wiki-entry><td><code>discreet</code></td><td>Yes / no</td><td>No</td><td>Only show the response to you. Defaults to true.</td></tr></tbody></table>
