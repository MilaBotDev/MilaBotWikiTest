## How to use

Type **/emojiclone** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>source</code></td><td>Text</td><td>Yes</td><td>A custom Discord emoji, sticker URL, or Discord-hosted image URL.</td></tr>
<tr data-wiki-entry><td><code>target</code></td><td>Text</td><td>No</td><td>Choose whether to create an emoji or a sticker.<br>Choices: Emoji (<code>emoji</code>), Sticker (<code>sticker</code>)</td></tr>
<tr data-wiki-entry><td><code>name</code></td><td>Text</td><td>No</td><td>Optional name for the cloned expression.</td></tr>
<tr data-wiki-entry><td><code>tag</code></td><td>Text</td><td>No</td><td>Optional emoji tag when creating a sticker.</td></tr></tbody></table>
