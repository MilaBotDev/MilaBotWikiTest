## How to use

Type **/vitrine** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>action</code></td><td>Text</td><td>No</td><td>What to do with your vitrine.<br>Choices: View (<code>view</code>), List plates (<code>list</code>), Set treat (<code>set_candy</code>), Set plate (<code>set_plate</code>), Clear slot (<code>clear</code>)</td></tr>
<tr data-wiki-entry><td><code>slot</code></td><td>Whole number</td><td>No</td><td>Vitrine slot (required when changing a slot).<br>Choices: Slot 1 (<code>1</code>), Slot 2 (<code>2</code>), Slot 3 (<code>3</code>)</td></tr>
<tr data-wiki-entry><td><code>candy_id</code></td><td>Text</td><td>No</td><td>Treat ID from patisserie.json; used with Set treat.</td></tr>
<tr data-wiki-entry><td><code>plate_id</code></td><td>Text</td><td>No</td><td>Plate ID; used with Set plate.</td></tr></tbody></table>
