## How to use

Type **/roleinfo** in Discord and select MilaBot’s command. Required inputs are marked below; optional inputs can be left blank.

This command is for servers.

## Options


<table><thead><tr><th scope="col">Option</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">What it does</th></tr></thead><tbody><tr data-wiki-entry><td><code>role</code></td><td>Role</td><td>Yes</td><td>The role to inspect.</td></tr>
<tr data-wiki-entry><td><code>discreet</code></td><td>Yes / no</td><td>No</td><td>Only show the response to you. Defaults to true.</td></tr>
<tr data-wiki-entry><td><code>channel</code></td><td>Channel</td><td>No</td><td>Inspect this role's access in a server channel.</td></tr></tbody></table>
