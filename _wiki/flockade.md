## Draft and duel

Run **/flockade** with an optional opponent. Normal mode uses a **2×2** board and four duels; **hardmode** uses **2×3** and six. Choose a piece and place it in a square. When the boards fill, squares duel in sequence.

Win more duel points to win a round. The first to two round wins takes the match. A drawn round awards a win to both players.

## Piece matchups

**Sword beats Scribe. Scribe beats Shield. Shield beats Sword.** Shepherd loses to all three and ties another Shepherd. Matching categories tie unless an ability changes the result.

There are **36 pieces**: ten each for Sword, Shield, and Scribe (one plain and nine blessed), plus six blessed Shepherds.

## Regular blessings

| Blessing | Effect |
| --- | --- |
| Just | Wins against another piece of its own category. |
| Fallen / Risen | Moves pieces in its column down / up when dueling begins. |
| Prize | Awards two points when it wins a duel. |
| Rotten | Nullifies blessings on the opposite row when played. |
| Scout | Replaces an enemy piece; if there is none, it can be placed normally. |
| Mercenary | Swaps with its horizontal neighbor when dueling begins. |
| Marked | Makes the opponent lose one point when it wins. |
| Trickster | Becomes another piece when dueling begins. |

## Shepherd blessings

| Blessing | Effect |
| --- | --- |
| Lone | The opponent draws one piece instead of three. |
| Wandering | Gains two points each time it moves. |
| Guardian | Wins the round when dueling a piece marked by the wolf. |
| Rotten+ | Nullifies all opposing blessings when played. |
| False | Awards two points when it loses a duel. |
| Golden | Doubles points won in duels. |

The supplied artwork also includes Trickster+, but it is not an active piece in this version.

## Playback

Duels show an animated sequence. Use **Skip animation** to move past the playback, or **Replay** to start another match once it ends.
